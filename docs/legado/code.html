Motor-Marga v1.0

Producción Estable

Motor central de versionado de esquemas, migraciones concurrentes y grafo dinámico para PostgreSQL y ClickHouse. Permite aislar ramas de base de datos idénticas a repositorios Git con verificación de bloqueos cero (zero-lock dry runs).

Terminal / Bash

# Instalación CLI de Marga

$ curl -fsSL https://get.marga.dev | bash

# Vinculación de base de datos activa

$ marga link postgresql://user:secret@pg.internal:5432/core --branch main

# Ejecución de dry-run sin downtime

$ marga migrate up --dry-run --analyze-locks
